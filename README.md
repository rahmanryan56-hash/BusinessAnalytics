# Business Analytics Coursework

## Overview

Business Analytics coursework focused on forecasting neonatal care demand and using simulation modelling to analyse patient flow and waiting times in a hospital emergency department.

## Key Areas

* Time series analysis and forecasting techniques
* Naïve, moving average and exponential smoothing methods
* Forecast accuracy evaluation using MAPE
* Least squares regression and relationship analysis
* Spreadsheet-based discrete-event simulation
* Comparing hospital staffing scenarios and recommending improvements

## Tools

* Microsoft Excel
* Spreadsheet modelling
* Data analysis and visualisation
